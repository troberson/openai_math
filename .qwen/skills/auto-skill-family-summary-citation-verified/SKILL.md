# Writing a citation-verified family summary (template pipeline)

The manual write-and-verify workflow (hand-write a page, number sources by hand, three
hand-rolled passes) is retired. The `math-cgv` epic moved summary pages to a jinja2
template pipeline: one hand-written skeleton renders the mechanical surface, a
per-family data file supplies the prose, and the renderer resolves every quote
through a math-mode-aware normalizer. The verification is the checker
(`verify_summaries.py`) and its extracted self-tests.

Before the first page of a batch, read `references/quotation-traps.md` — the measured
defects from the 60 shipped pages, the normalizer contract, the banned-macro list,
and the per-manuscript macro divergence.

## 0. Pick the source layer from the ledger row first

Read the row before writing a sentence: `paps`, `paps_form`, `tier`, `chal`,
`mainres`, `scope_note`, `verification`, `trace`, `shapes`, `resolves_named`,
`companions`, `summary`.

`summary=1` means a page already exists for this family — check it before writing,
and never write a second page for the same family under a different discipline dir.
The ledger keys the column on the `<NNN>` prefix precisely so a misfiled page
still shows up. For batch work, the per-page steps, the batch gates, and the
decision ledger live in `notes/development/summaries-workflow.md`.

- **T0 (`paps_form=0`)**: no Lean, no scope note, no challenge, no trace. The
  manuscript LaTeX under `build/` is the *only* source. State it where the reader
  meets it — in the graduate section's formalization-status paragraph: "Nothing
  about this family is machine-checked." Not in a preamble. **Enumerate the
  manuscript root with `ls` before writing what it ships.**
- **Formalized**: read `lean/docs/<NNN>.md` first — its `## Scope` section states
  the exclusions, which are load-bearing — then the manuscript.
- Manuscripts ship LaTeX, so **PDF extraction is never needed**. Read
  `build/main.tex`, `build/sections/*.tex`, `build/references.bib`.

Label the epistemic status of every sentence: source-level (manuscript text),
release-level (what `CONTENTS.md` / `overview.tex` claims), or **prior** (the
assistant's training data). "Proves" in an abstract is a claim, not a verified
result.

## 1. The three layers

| Layer | File | Authority |
|---|---|---|
| Skeleton | `notes/templates/summaries/summary.md.j2` | Owns the mechanical surface: title line, breadcrumbs, canonical headings, Sources table, Links, Bibliography |
| Data file | `notes/data/summaries/<NNN>.md` | Per-family prose with `{{seq}}` quote tokens, a sources block, a quotes block, a family/slug line |
| Rendered page | `notes/summaries/<discipline>/<NNN>-<slug>.md` | Generated by `build_summaries.py`; never hand-edited |

The skeleton is the only place a generated page's text lives. The data file is the
hand-maintained root. The rendered page is a function of the two; a hand edit to a
page is reverted by the next render.

## 2. Author the data file

The data file carries four things:

1. **A `<!-- sources` block**: one row per file, `S#\t<repo-relative path>\t<role>`.
   The path is the full repository-relative path in backticks (the checker resolves
   cells under the manuscript root and the repo root; a bare name that exists under
   both is a counted problem).
2. **A `<!-- quotes` block**: one row per quote token,
   `seq\t<which>\t<S#>\t<start>\t<end>\t<span>`. The span is the verbatim source
   text (LaTeX, not rendered markdown). `which` is `inline` or `block`.
3. **A `<!-- family NNN -->` and `<!-- slug ... -->` line**: the slug is the
   mechanical slug of the overview title (NFKD, strip combining marks, drop
   LaTeX escapes, lowercase, non-alphanumerics → `-`, leading `the-` dropped).
   The renderer re-derives the slug from the ledger title; the data file's slug is
   a transcription that drifts the moment the title changes.
4. **The section bodies**: `## contents`, `## undergraduate`, `## graduate`,
   `## history`, `## consequences`, `## section_skeleton`, `## formalized`,
   `## coverage`. Each body is prose with `{{seq}}` tokens where a quote belongs.
   A section with no body is omitted from the rendered page (the skeleton's
   `{% if %}` guard).

### The quote token convention

The body cites `{{3}}` (an inline quote) or a block quote as a standalone
`> {{1}}` line. The token's content comes from the quotes block: the span is the
verbatim source text, and the renderer feeds it to the normalizer. The body never
carries the source text directly — it carries the token, and the token resolves
to the normalized span. This is what makes the data file self-sufficient: the
renderer does not read `quotes.tsv` (which is the provenance record the seeder
maintains), it reads the data file's own quotes block.

### The sources block

One row per file. The path is the full repository-relative path:
`preprints/<dir>/build/paper.tex`, `overview.tex`, `lean/docs/<NNN>.md`,
`lean/OAI/...`, `lean/ComparatorChallenges/...`. The role is a short phrase
("Abstract, theorems, proof overview", "Scope", "Comparator stub"). The checker
parses every row: a path that does not exist on disk is a problem, a path that
resolves under both the manuscript root and the repo root is a problem
(`AMBIGUOUS`), and a declared-but-never-cited source is a note (cite it in the
body or delete the row — deleting a middle row renumbers every later marker).

### Section bodies

The undergraduate and graduate sections are the **same argument at two depths**.
The 1–3 paragraphs are prose; the proof sketch maps one-to-one onto the moves in
the graduate section. Rules that keep the undergraduate register honest: no word
appears that the section has not defined in the same sentence; and the sketch is
sourced, not invented.

No preamble between the title and the first heading, and no provenance lead-in
under a heading. The one label that stays is inline: **Prior (my training data,
not this repo).** at the start of a paragraph that is not repo text.

## 3. Run the renderer

```
python3 notes/scripts/build_summaries.py
```

The renderer is pure over its digest key: it reads the working-tree templates and
data files, resolves each quote through the normalizer, and stages the rendered
pages. A second run with the same inputs produces identical bytes. `--check-only`
runs the full measurement and writes nothing.

The renderer:
- Reads the skeleton and the data file.
- Resolves each `{{seq}}` token through `normalizer.normalize_window(span, preamble)`,
  where the preamble is the manuscript's own (for macro expansion).
- Builds the Sources table (line counts from disk), the Links section (relative
  paths from the page directory), and the Bibliography section (from `.bib` files
  and `\begin{thebibliography}` blocks in the declared sources).
- Renders through the skeleton with `trim_blocks=True, lstrip_blocks=True`.
- Stages all 60 pages plus the index `README.md`, promotes the tree, and sweeps
  any stale page a title change orphaned.

## 4. The normalizer contract

The normalizer (`catlib/normalizer.py`) is the math-mode-aware LaTeX → markdown
renderer for quote windows. It is the complement of `catlib.text.strip_markup`:
that function is lossy by design (it compares a page quotation against the line
it cites); the normalizer preserves the math, so a `$x + y$` in the source
becomes a rendered `$x + y$` in the page.

`normalize_window(span, preamble)` does, in order: build a **per-manuscript**
macro table from `\newcommand` in the preamble (macro bodies diverge per
manuscript, so a global table is wrong); split the window into math and prose
regions; expand manuscript macros in math (with `#1`-style argument
substitution) and wrap in `$...$`; apply the fixed prose transforms (accents to
unicode, `\emph`→`_x_`, `\textbf`→`**x**`, `\text`→content, drop
`\cite`/`\ref`/`\Cref`/`\eqref`); emit a statement `\begin{X}` lead-in when the
window opens with one; and fence a span that carries a banned macro with no safe
form in a `latex` code block, so an unrenderable macro never reaches the page as
a live command.

The full contract — the banned-macro list, the per-manuscript macro divergence
(measured floors), the parameterized-body examples, the statement lead-in
vocabulary split, the accent rule, and the fenced-code fallback — is in
`references/quotation-traps.md` (the normalizer-contract section). Before writing
a quote, check the source line for a banned macro; if it carries one with no safe
form, the normalizer fences it, and that is correct, not a defect.

## 5. Verify the rendered page by script

The checker is `notes/scripts/verify_summaries.py`. It:
- Resolves every `[Sn:line]` marker against the shipped file.
- Checks every quotation verbatim-modulo-whitespace against the lines it cites.
- Counts a File cell that resolves under both roots as a problem.
- Writes nothing.

Run it with:
```
python3 notes/scripts/verify_summaries.py
```

Its mutants live in `notes/scripts/tests/test_summaries.py`, run with:
```
python3 notes/scripts/run_tests.py notes/scripts/tests/test_summaries.py -q
```

The test file injects the defects: a real quotation corrupted in each form the
page uses (inline, inline wrapped across lines, block quote), one fabricated
quotation, the manuscript root retargeted to a superseded sibling, and a bare
locator citation moved above the family's own block. A green pass you have never
seen go red is not a check.

### Additional verification tools

- `check_summary_manuscripts.py` — which manuscripts each page reads, and
  whether the release still names them.
- `locate_summary_quotes.py <page.md>` — where a quotation's text actually sits,
  when `verify_summaries.py` reports a miss.
- `read_manuscript.py <preprints-dir>` — prints a manuscript's abstract,
  section skeleton, and titled statement environments with `file:line` anchors.
  The reading entry point for a manuscript.

All three write nothing.

## 6. Traps

Read `references/quotation-traps.md` for the full list. The dominant failure
modes, in order of frequency:

- **A shell dump is not a read.** Dump the window to a file under `.qwen/tmp/`,
  read that file with `read_file`, and write the quote from the checker's
  `line says` column.
- **A paraphrase inside quotation marks is a fabrication.** If you cannot paste
  the source text, do not put it in quotes — write it as your own prose.
- **Off-by-one at a range endpoint.** LaTeX source wraps sentences mid-line.
  Derive every range from the shipped file, never from a paragraph boundary
  you remember.
- **A quotation needs a marker of its own.** Two quotes in one paragraph where
  only the second carries a marker leaves the first matched against the
  second's range.
- **Precomposed accents never match the LaTeX macro.** `Erdős` fails against
  source `Erd\H{o}s`. Quote each from its own source, verbatim.
- **A File cell that resolves under both roots is a counted problem.** Use the
  full repository-relative path.
- **A range marker must not end on a file's trailing blank line.** Check both
  ends of every range.
- **`read_file` window can return bytes the file does not contain.** A read is
  trustworthy only when the checker agrees with it.
