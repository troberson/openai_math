## Not checked

- Nothing here says a proof is correct. `formalized` is the yaml `sources:` flag at source level; `review: status: unchecked` and `automation: methods: [agent]` apply.
- No `.lean` file was opened and nothing was built, so a Lean link says the yaml names a file that exists on disk, not that it elaborates.
- Citation edges are untyped: the release records no builds-on / contrasts-with relation, so an edge is a citation choice, not consequence.
- The family→Lean reach is derived through scope-note config links. The release ships no manuscript→Lean edge, so the formalized manuscripts are not individually linked to a Lean file.
- Claim shapes are keyword floors carried from `notes/catalog.tsv`, not a census: families match three or more shapes and others match none.
- No topic assignment is rendered; `notes/index/topics.tsv` is `math-u41.3`.
- Link targets were checked for existence at render time, not for content: a link resolving to a file says the file is there, not that it says what the page claims.
