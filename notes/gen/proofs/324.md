# 324 — Lipschitz equivalence without linear isomorphism

## Bi-Lipschitz c0 absorption without a linear copy, and Lipschitz-equivalent but non-linear-isomorphic spaces

**Match.** This family carries two manuscripts. The first [S2:51]{2} proves that there is a separable real Banach space Z containing no closed linear subspace isomorphic to c0, and an onto bi-Lipschitz map from Z ⊕∞ c0 onto Z. The second [S3:21]{3} proves that there are separable real Banach spaces X, Y and a bijection Ψ with explicit bi-Lipschitz bounds making X and Y Lipschitz equivalent but not linearly isomorphic. The Lean carries both claims: `main_result : MainConclusion` [S4:33]{4} assembles the concrete C0-absorption space, and `main : MainClaim` [S5:8]{5} proves the Lipschitz counterexample via the separating-stages method. The scope note [S1:10]{1} records the Lipschitz alignment. Zero sorry in both closures.
