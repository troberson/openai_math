# 130 — Fourier transforms below $n\log n$

## statement

Family 130 ships two preprints with two main theorems. The subsequential
bound 

> **Theorem 1.1**
In this model,
$$\liminf_{n\to\infty}\frac{L(n)}{n\log_2 n}=0.$$
Equivalently, for every $`c>0`$ and every integer $`N_0\ge2`$, there is an
integer $`n\ge N_0`$ and an exact circuit for $`F_n`$ with fewer than
$`c n\log_2 n`$ gates. [S1:46–54]

The uniform power saving 

> **Theorem 1.1**
There is a single deterministic algorithm which, for every positive integer $`n`$ and every $`x\in\mathbb C^n`$, computes $`F_nx`$ exactly. In the model above, including scalar preparation, schedule construction, and index work, its running time is
$$O\!\left(n(\log n)^\theta(\log\log n)^{4-\theta}\right)$$
as $`n\to\infty`$. It suffices to supply the specified root $`\zeta_{D_*}`$ for an explicitly computable integer $`D_*<1024n^3`$. [S2:85–91]


## the subsequential match

The `MainStatement` [S3:47–50] encodes the preprint's Theorem 1:

| Preprint clause | Lean encoding | Verdict |
|---|---|---|
| $`\liminf_{n\to\infty} L(n)/(n\log_2 n) = 0`$ | `∀ c > 0, ∀ N₀ ≥ 2, ∃ n ≥ N₀, cost < c·n·log₂ n` [S3:48–50] | **Match** (equivalent form) |
| For every $`c > 0`$ | `∀ c : ℝ, 0 < c →` [S3:48] | **Match** |
| For every cutoff $`N_0 \ge 2`$ | `∀ N₀ : ℕ, 2 ≤ N₀ →` [S3:48] | **Match** |
| Some $`n \ge N_0`$ | `∃ n : ℕ, N₀ ≤ n` [S3:49] | **Match** |
| Circuit with $`< cn\log_2 n`$ gates | `C.size < c * n * Real.logb 2 n` [S3:50] | **Match** |
| Exact DFT | `C.Computes (fourierMatrix n)` [S3:49] | **Match** |

The Lean uses the preprint's own "equivalently" form: $`\liminf = 0`$ iff
$`\forall c > 0, \forall N_0, \exists n \ge N_0`$ with cost $`< cn\log_2 n`$.
The proof is `main_theorem : MainStatement := win_to_fourier finite_win`
[FourierCircuit/Main.lean:277], a single line lifting the finite
tensor witness `finite_win` to the circuit statement.

## the uniform match

The `TimeBounds` [S4:75–77] requires the work function $`W`$ to satisfy
three asymptotic bounds simultaneously:

$$W' = O(\text{paperTime}) \quad\wedge\quad W' = O(\text{decimalTime})
\quad\wedge\quad W' = o(n\log n)$$

where [S4:32–33]:

- `paperTime n = n · (log n)^θ · (log log n)^{4-θ}` — the preprint's
  **exact parametric form**, with `θ = log(10^6 - 6871402692000000/2^71)
  / log(10^6)` [S4:25–29].
- `decimalTime n = n · (log n)^{1-10^{-13}}` — the simplified decimal
  exponent [S4:30,35].

The preprint's Theorem 1 [S2:86–90] states the running time as
$`O(n(\log n)^\theta(\log\log n)^{4-\theta})`$. The Lean proves
**exactly this form** (via `paperTime`) **plus** the decimal corollary
(via `decimalTime`) **plus** the qualitative $`o(n\log n)`$ claim. This
is a **strengthening**: the preprint states one of the three bounds;
the Lean proves all three.

| Preprint clause | Lean encoding | Verdict |
|---|---|---|
| Single deterministic algorithm | `∃ order solve W` (fixed programs) [S4:79] | **Match** |
| For every positive integer $`n`$ | `∀ n : ℕ, 0 < n` in `DFTProgram` [Goal.lean:50] | **Match** |
| Computes $`F_n x`$ exactly | `result.val = dft n x` in `DFTProgram` [Goal.lean:58] | **Match** |
| $`O(n(\log n)^\theta(\log\log n)^{4-\theta})`$ | `W' =O paperTime` [S4:77] | **Match** (exact form) |
| Root of unity supplied | `d.val < 1024*n^3` in `DFTProgram` [Goal.lean:54] | **Match** |
| Convolution | `ConvGoal` [S4:81] | **Match** (beyond preprint theorem) |

The `DFTGoal` [S4:79] and `ConvGoal` [S4:81] are zero-argument `Prop`s:
each exists over a single triple `(order, solve, W)` that works for all
$`n`$. The `ConvGoal` adds the full convolution result, which the
preprint's Theorem 1 does not state separately (it is a corollary in
the synthesis section). The scope note [S5:12] confirms: "computing
the canonical discrete Fourier transform **and the full convolution**
of two length-$`n`$ complex vectors exactly."

## findings

- **Both results proven**: 2 of 2 comparator results are `main_results`
  entries — the subsequential $`cn\log_2 n`$ bound and the uniform
  $`o(n\log n)`$ DFT + convolution.
- The subsequential bound is a **clean match**: the Lean uses the
  preprint's own "equivalently" form, with the same $`c`$, $`N_0`$, $`n`$
  quantifier structure and the same $`cn\log_2 n`$ cost bound.
- The uniform bound is a **strengthening**: the Lean proves the
  preprint's exact parametric form `paperTime` **plus** the decimal
  corollary `decimalTime` **plus** the qualitative $`o(n\log n)`$ claim.
  The preprint states only the first; the Lean proves all three.
- The scope note [S5:10, S5:12] accurately describes both results and
  correctly notes the subsequential nature of the first and the
  synthesis appendix's uniformization being outside the selected
  statements for the second.
- No faithfulness issues found.
