# 118 — Unbounded bin-packing gaps and the modified integer round-up conjecture

## statement

The preprint's two main theorems:

> **theorem**
For every integer $`c\ge0`$, there is a finite rational bin-packing instance
$`I`$ and an integer $`B`$ such that every item size exceeds $`1/6`$ and
$$\mathrm{OPT}_{\mathrm{LP}}(I)=B,
  \qquad \mathrm{OPT}(I)>B+c.$$
The equality for the fractional optimum also holds for the configuration
LP whose patterns are subsets of the individual item copies. [S1:87–96]

> **theorem**
For every fixed integer $`c\ge0`$, it is NP-hard to distinguish pairs $`(I,B)`$
such that $`I`$ packs into $`B`$ bins from pairs such that $`I`$ cannot be packed
into $`B+c`$ bins. Here $`B`$ is an integer supplied with the instance,
the item sizes are rational, and every item size is strictly greater
than $`1/6`$. [S1:106–112]

The Lean proves both in a single declaration with four conjuncts:

```lean
theorem main_results :
    (∀ c : ℕ, ∃ I : Instance, ∃ B : ℕ,
      I.n = 5 * B ∧
      (∀ i, (1 / 6 : ℚ) < I.size i ∧ I.size i < 1) ∧
      B + c < opt I ∧ individualLP I = (B : ℝ) ∧ typeLP I = (B : ℝ)) ∧
    (∀ c : Nat, PackingGapNPHard c) ∧
    ((∃ c : Nat, Nonempty (AbsoluteAdditiveAlgorithm c)) ↔ PEqualsNP) ∧
    (PEqualsNP → ∃ algorithm : AbsoluteAdditiveAlgorithm 0,
    (∀ (items : RawInstance) (valid : items.Valid), ∃ packing : RawPacking,
      algorithm.run (BinaryEncoding.rawInstanceBits items) = some packing ∧
      packing.Feasible items ∧ packing.bins = opt (items.toInstance valid)) ∧
    algorithm.run (BinaryEncoding.rawInstanceBits []) = some ⟨0, []⟩ ∧
    (∀ input : List Bool, BinaryEncoding.decodeRawInstance input = none →
      algorithm.run input = none) ∧
    (∀ items : RawInstance, ¬ items.Valid →
      algorithm.run items = none)) := by
```
[S2:7–22]

The scope note [S3:9] describes the formalization as ruling out a
universal additive bound for the configuration LP.

## the match

The four conjuncts of `main_results` correspond to the preprint's claims:

| Preprint claim | Lean conjunct | Verdict |
|---|---|---|
| $`\forall c \ge 0`$: instance with $`\mathrm{OPT}_{\mathrm{LP}}(I) = B`$, $`\mathrm{OPT}(I) > B+c`$, sizes $`> 1/6`$ [S1:87–96] | `(∀ c, ∃ I, ∃ B, I.n = 5*B ∧ (∀ i, 1/6 < size_i < 1) ∧ B+c < opt I ∧ individualLP I = B ∧ typeLP I = B)` [S2:8–11] | **Match** |
| NP-hard to distinguish $`B`$-bin from $`B+c`$-bin [S1:106–112] | `(∀ c, PackingGapNPHard c)` [S2:12] | **Match** |
| — (corollary: $`P=NP`$ iff additive algorithm) | `((∃ c, Nonempty (AbsoluteAdditiveAlgorithm c)) ↔ PEqualsNP)` [S2:13] | **Match** (corollary) |
| Under $`P=NP`$, optimal algorithm constructed | `(PEqualsNP → ∃ algorithm : AbsoluteAdditiveAlgorithm 0, …)` [S2:14–22] | **Match** (corollary) |

The first conjunct is a **strengthening** of the preprint's theorem:
- The preprint says "there is a finite rational bin-packing instance"
  [S1:88]; the Lean specifies `I.n = 5 * B` [S2:9] — the instance has
  exactly $`5B`$ items.
- The preprint says $`\mathrm{OPT}_{\mathrm{LP}}(I) = B`$ [S1:91]; the Lean says `individualLP I = B ∧ typeLP I = B` [S2:11] —
  **both** the individual-copy and size-type configuration LPs equal $`B`$,
  which is the stronger form stated in the scope note.
- The preprint says "every item size exceeds $`1/6`$" [S1:89]; the Lean
  adds the upper bound `I.size i < 1` [S2:10].

The NP-hardness conjunct [S2:12] matches the preprint's second theorem
verbatim: "for every fixed integer $`c \ge 0`$, it is NP-hard to
distinguish pairs $`(I,B)`$ such that $`I`$ packs into $`B`$ bins from pairs
such that $`I`$ cannot be packed into $`B+c`$ bins."

The two corollary conjuncts (the $`P=NP`$ equivalence and the optimal
algorithm construction) go beyond the preprint's theorems — they are
consequences the preprint states in its consequences section.

## findings

- **Clean match with strengthening**: the first conjunct specifies
  $`5B`$ items and both LP variants (individual and type), which the
  preprint states in words. The NP-hardness conjunct matches verbatim.
- The two corollary conjuncts ($`P=NP`$ equivalence, optimal algorithm)
  are consequences the preprint derives in its consequences section,
  not separate theorems — encoding them in the main declaration is a
  formalization choice, not a divergence.
- No faithfulness issues found.
