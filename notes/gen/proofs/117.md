# 117 — Uniform sparsest cut: hardness and semidefinite gaps

## statement

The preprint's main theorem:

> **theorem**
There are an absolute constant $`c>0`$ and capacity instances $`C^{(j)}`$
on $`n_j\to\infty`$ vertices, with $`\mathrm{GL}(C^{(j)})>0`$, such that
$$\frac{\mathrm{OPT}(C^{(j)})}{\mathrm{GL}(C^{(j)})}
\ge c\,\frac{\sqrt{\log n_j}}{(\log\log n_j)^3}$$
for all sufficiently large $`j`$. The demand is one between every pair
of distinct vertices. [S1:152–161]

The Lean proves the same content:

```lean
theorem mainGap :
    ∃ c : ℝ, 0 < c ∧
      ∃ n : ℕ → ℕ, ∃ C : (j : ℕ) → Capacity (n j),
        (∀ j, 2 ≤ n j) ∧
        Tendsto n atTop atTop ∧
        (∀ j, 0 < glValue (C j)) ∧
        ∀ᶠ j in atTop,
          c * Real.sqrt (Real.log (n j : ℝ)) / (Real.log (Real.log (n j : ℝ))) ^ 3 ≤
            OPT (C j) / glValue (C j) := by
```
[S2:14–22]

The scope note 

> The formalized result gives integrality gaps for the Goemans–Linial relaxation of uniform sparsest cut. Along a sequence of instance sizes $`n\to\infty`$, the ratio of the integral optimum to the positive relaxation optimum is at least $`c\sqrt{\log n}/(\log\log n)^3`$ for one absolute $`c>0`$. [S3:9]
