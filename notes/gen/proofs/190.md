# 190 — Polynomial removal fails for ordered binary matrices

## Polynomial removal fails for ordered binary matrices

**Match.** The single comparator target is proven as a `main_results` entry.

The preprint's main theorem [[2]] states that a fixed 66×66 binary matrix H has the property that for every h ≥ 1, there is an n_h × n_h binary matrix A_h at normalized edit distance at least ε_h from being H-free, with fewer than N_H(A_h) ≤ n_h^{132}·ε_h·2^{-h} induced ordered copies. The scope note [S1:9] records the same: for every c, C > 0, there is n and ε > 0 with a binary matrix at distance at least ε but with fewer than c·ε^C·n^{132} copies.

The Lean declaration `no_polynomial_removal_bound` [S2:26–34] [[1]] proves the same: ∀ c, C > 0, ∃ n ≥ 1, ∃ ε ∈ (0,1), ∃ A : BinaryMatrix n, with fixedDistance A ≥ ε and copyCount(fixedH, A) < c·ε^C·n^{132}. The proof delegates to `no_polynomial_removal_bound_of_sequence` applied to `counterexample_sequence`. The single comparator [S1:15] (`MatrixRemoval.lean`) is the shared target.
