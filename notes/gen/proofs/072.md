# 072 — Brennan's conjecture and a counterexample to Kraetzer's prediction

## statement

The preprint's critical-point-count argument uses the winding number of the
gradient field $`\nabla\ell`$ on the boundary of each superlevel component:

> is closed. Stokes' theorem \cite[Theorem 16.11]Lee2013 shows that the
winding on the outer boundary equals the sum of the windings on the
positively oriented small circles. At a nondegenerate critical point,
the gradient on a sufficiently small circle is homotopic through
nonzero vectors to its invertible linear part. Its index is consequently
the sign of $`\det\mathrm{Hess}\ell`$, namely $`+1`$ at a maximum and
$`-1`$ at a saddle. [S1:302–308]

The pole contributes the same 

> The negative radial leading field has winding number $`+1`$. Thus the pole
also contributes $`+1`$, although it is not a finite critical point. [S1:316–317]

The winding number is **convention-dependent**: its sign flips when the contour
orientation reverses. This makes 072 a *vulnerable-class* family — the sign is a
mathematical invariant the Lean must set correctly, and a flip is invisible to the
kernel if the final count is sign-insensitive.

## the sign convention in the Lean

The orientation is a `Bool` flag [S2:21]:

```lean
def orientedDifference (positive : Bool) (a z : ℂ) : ℂ :=
  if positive then z-a else conj (z-a)
```
[S2:21–22]

`positive = true` gives $`z-a`$ (positively oriented); `positive = false` gives
$`\overline{z-a}`$, which conjugates the field and **negates the winding number**.
The lemma that carries the sign [S2:245]:

```lean
lemma windingNumber_orientedDifference (γ : C(unitInterval, ℂ)) (hloop : γ 1 = γ 0)
    (p : Bool) (a : ℂ) (ha : ∀ t, γ t ≠ a) :
    windingNumber ⟨fun t => orientedDifference p a (γ t),
      (continuous_orientedDifference p a).comp γ.continuous⟩ =
      (if p then 1 else -1) * loopIndex γ a := by
```
[S2:245–249]

The flag is set at the two critical-point cases:

```lean

    linearPart A ≠ 0 ∧ ∃ r : ℝ, 0 < r ∧ ∀ w : ℂ, ‖w-a‖ < 2*r → w ≠ a →
      X w / (linearPart A*orientedDifference true a w) ∈ Complex.slitPlane := by
```

[S2:183–187]

```lean
lemma exists_slit_radius_neg {X : ℂ → ℂ} {a : ℂ} {A : ℂ →L[ℝ] ℂ}
    (hzero : X a = 0) (hd : HasFDerivAt X A a)
    (hdet : LinearMap.det A.toLinearMap < 0) :
    antiLinearPart A ≠ 0 ∧ ∃ r : ℝ, 0 < r ∧ ∀ w : ℂ, ‖w-a‖ < 2*r → w ≠ a →
```

In the `det > 0` case (maximum) the field is divided by
`orientedDifference true`; in the `det < 0` case (saddle) by
`orientedDifference false`. The same `true`/`false` split feeds every
positively-oriented feature downstream.

## sign audit

Protocol: [`README.md`](../../data/proofs/README.md). 072 is **vulnerable-class** — the winding
number is a convention-dependent signed invariant, and the preprint pins the
convention, so there is a checkable target.

| Preprint convention | Lean | Verdict |
|---|---|---|
| max → index $`+1`$ ($`\det\mathrm{Hess}>0`$) | `det > 0` → `orientedDifference true` → `+1` [S2:187] | **Match** |
| saddle → index $`-1`$ ($`\det\mathrm{Hess}<0`$) | `det < 0` → `orientedDifference false` → $`-1`$ [S2:200] | **Match** |
| pole → $`+1`$ | negative radial field; `true` branch | **Match** |
| outer = sum of inners (Stokes) | additivity of `windingNumber_mul` [S2:250] | **Match** |
| contours positively oriented | `true` branch ($`z-a`$, not conjugate) | **Match** |

No sign divergence. The `Bool` flag is set to `true` at every positively
oriented feature (max, pole, boundary) and `false` at the saddle (det < 0),
matching the preprint's convention line by line.

**Assembly chain.** The per-critical-point signs carry through to the final
count via two load-bearing lemmas, both using the **same** sign predicate
`0 < J`:

- `signed_sum_eq_card_sub` [S2:598] converts the signed sum to a
 cardinality difference:

 ```lean
lemma signed_sum_eq_card_sub (s : Finset ℂ) (J : ℂ → ℝ)
    (hJ : ∀ z ∈ s, J z ≠ 0) :
    (∑ z ∈ s, if 0 < J z then (1 : ℤ) else -1) =
      (s.filter (fun z => 0 < J z)).card - (s.filter (fun z => J z < 0)).card := by
```
[S2:598–601]

- `critical_count` [S3:478] concludes:

 ```lean
theorem critical_count {f : ℂ → ℂ} (hf : UnivalentOn f halfPlane)
    {k : ℝ} (hk : 0 < k) {ξ : ℂ} (hg : GoodPair f k ξ) {h : ℝ} (hh : 0 < h) :
    let critical := {z | z ∈ halfPlane ∧ criticalMap f k z = ξ ∧
      ENNReal.ofReal h ≤ potential f k ξ z}
    critical.Finite ∧ ({z ∈ critical | 0 < normalizedJacobian f k z}).ncard ≤
      ({z ∈ critical | normalizedJacobian f k z < 0}).ncard := by
```
[S3:478–483]

The final statement is an **inequality between cardinalities split by
sign**. A sign flip swaps the two sides, producing a different (and false)
statement. This makes 072 *less* vulnerable than 032: 032's conclusion was
sign-insensitive ($`I_{\text{new}} \neq 0`$), so a sign error was invisible
to the kernel. 072's conclusion is sign-sensitive — the Lean kernel can
catch a swap because the swapped statement does not follow from the
hypotheses.

**Full coverage:** the audit covers the local per-critical-point signs
(max $`+1`$, saddle $`-1`$, pole $`+1`$), the assembly (`signed_sum_eq_card_sub`,
`critical_count`), and the statement structure (sign-sensitive inequality).
No gap remains.

## why the keyword census mis-ranks this family

The signed-quantity keyword census ranks 072 at `winding=124, orient=59`, but
it ranks family 105 at `signed=600` — higher. 105 is a **false positive**: its
`signed` markers are `SignTuple`, `evaluateSignedTape`, `SignedMultiplicity`,
a computational tape-encoding for a probability sampler, not a mathematical
sign convention. A sign audit on 105 would check sampler bookkeeping the
preprint makes no convention claim about. The keyword census is a **candidate
generator**, not a classifier: it cannot distinguish `signed` as a
mathematical invariant from `signed` as a data structure, so candidates
must be read before they qualify. 072 qualifies; 105 does not.

## findings

- Winding-number sign convention: **matches** (max $`+1`$, saddle $`-1`$, pole $`+1`$,
  positively oriented).
- Assembly chain: **consistent** — `signed_sum_eq_card_sub` and `critical_count`
  use the same sign predicate `0 < J` as the per-critical-point split.
- Statement structure: **sign-sensitive** — the conclusion is an inequality between
  cardinalities split by sign; a sign flip would swap the sides. This makes 072
  *less* vulnerable than 032, whose conclusion was sign-insensitive.
- Full coverage: no gap remains.
- Method: the keyword census over-ranks 105 (computational `signed`) and
  under-ranks 072 (true convention-dependent winding) — census is a candidate
  generator, not a classifier.
