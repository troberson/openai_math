# 103 — Derandomization of logarithmic space: $\mathsf L=\mathsf{RL}=\mathsf{BPL}$

## statement

The preprint's main theorem:

> **theorem**
$$\mathsf L=\mathsf{RL}=\mathsf{BPL}.$$ [S1:28–32]

The Lean declaration proves exactly the stated equality, as a conjunction
of the two subset equalities:

```lean
/-- Deterministic, one-sided randomized, and two-sided randomized logarithmic space coincide. -/
theorem exact_logarithmic_space_derandomization :
     L=RL ∧ RL=BPL:=by
   have ht:= RL_subset_BPL.trans BPL_subset_L
   exact ⟨Set.Subset.antisymm L_subset_RL ht,
                           Set.Subset.antisymm RL_subset_BPL (BPL_subset_L.trans L_subset_RL)⟩
```
[S2:103–108]

The proof is a three-inclusion chain assembled by antisymmetry: `L ⊆ RL`
[S3:546], `RL ⊆ BPL` [S4:227], and `BPL ⊆ L` [S2:82]. Antisymmetry turns
mutual inclusivity into equality for each pair.

```lean
/-- Every bounded-error probabilistic logspace language has a deterministic logspace decider. -/
theorem BPL_subset_L : BPL ⊆ L:=by
```
[S2:82–83]

The `BPL_subset_L` inclusion is the load-bearing one — the derandomization
step. It takes a bounded-error probabilistic logspace machine and produces a
deterministic logspace decider by approximating the acceptance probability
via `fixed_precision_estimator` and thresholding.

## class definitions

The preprint pins the class semantics:

> The class $`\mathsf L`$ consists of languages decidable by deterministic
machines in $`O(\log(n+2))`$ work space. Such a halting deterministic
machine has only polynomially many configurations and hence runs in
polynomial time. The class $`\mathsf{RL}`$ permits
polynomial-time randomized machines in this space, with acceptance
probability zero on no inputs and at least $`1/2`$ on yes inputs.
For $`\mathsf{BPL}`$, the corresponding probabilities are at most $`1/3`$ and at
least $`2/3`$. [S1:19–26]

These match the Lean's class definitions and the scope note [S5:9]:
$`\mathsf{RL}`$ is one-sided (probability zero on no-instances, at least $`1/2`$
on yes-instances) and $`\mathsf{BPL}`$ is two-sided (at least $`2/3`$ on yes, at
most $`1/3`$ on no). The randomized classes use polynomial time, as the scope
note states.

**Match** — the preprint's probability thresholds ($`1/2`$, $`1/3`$, $`2/3`$) appear
in the Lean's class definitions and the scope note.

## the quantitative compiler

The preprint's second theorem gives the quantitative form: a deterministic
algorithm that approximates the acceptance probability to $`2^{-q}`$ at
$`O(\log(n+2)+q)`$ workspace and $`(n+2)^{O(1)}2^{O(q)}`$ time:

> **theorem**
Fix a randomized machine $`\mathcal M`$ with polynomial worst-case
running time and $`O(\log(n+2))`$ work space. Let $`p_{\mathcal M}(x)`$ be
its acceptance probability on an input $`x`$ of length $`n`$. There is a
uniform deterministic algorithm which, on input $`(x,1^q)`$ with $`q\ge1`$,
outputs an integer $`0\le a\le2^{q+2}`$ satisfying
$$\left|a2^{-(q+2)}-p_{\mathcal M}(x)\right|\le2^{-q}.$$
It uses $`O(\log(n+2)+q)`$ work space and
$`(n+2)^{O(1)}2^{O(q)}`$ time. The constants depend only on $`\mathcal M`$. [S1:40–51]

The scope note [S5:11] is explicit about the boundary: "The paper's explicit
compiler and numerical running-time bounds are not separately stated in this
Comparator target." The Lean proves the equality via the `fixed_precision_estimator`
inside `BPL_subset_L`, so the derandomization mechanism is present, but the
quantitative workspace/time bounds as a separate theorem are not declared.
This is a **coverage boundary** — the equality holds in the Lean, and the
estimator that underlies it is there, but the $`q`$-parameterized precision bound
is not a standalone declaration.

## findings

- Equality $`\mathsf L=\mathsf{RL}=\mathsf{BPL}`$: **matches** — proven by assembling
  `L_subset_RL`, `RL_subset_BPL`, `BPL_subset_L` via antisymmetry [S2:107–108].
- Class semantics: **matches** — one-sided $`\mathsf{RL}`$ and two-sided $`\mathsf{BPL}`$ with the
  preprint's exact probability thresholds.

  `fixed_precision_estimator` to produce a deterministic logspace decider.
