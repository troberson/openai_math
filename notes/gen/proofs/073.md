# 073 — The Falconer distance conjecture

## Falconer distance conjecture in all dimensions

**Match.** The manuscript's headline [S2:8] is the all-dimensional Falconer distance conjecture: for every integer $`d \ge 2`$ and compact $`E \subset \mathbb{R}^d`$ with $`\dim_H E > d/2`$, the distance set has positive Lebesgue measure. The Lean carrier `MainTarget` [S4:32] states exactly this — `∀ (d : ℕ), 2 ≤ d → ∀ E : Set (Space d), IsCompact E → (d : ℝ≥0∞) / 2 < dimH E → 0 < volume (distanceSet E)` — with the dimension bound as an open inequality in non-negative reals and the conclusion as positive volume of the distance set, matching the manuscript point for point. The scope note [S1:9] records the same alignment.

The declaration `OAI.PlanarFalconer.mainTarget_proved` [S3:50] proves `MainTarget` by direct reference to the proved lemma `manuscript_main` in `AllDimensions.lean` — a one-line proof of the *target statement*, whose body is the all-dimensional estimate. Zero `sorry` in the closure. This is a genuine Match: the Lean statement is the manuscript's claim, and the proof discharges it, not a rephrased or weaker version.

The comparator stub `FalconerAllDimensions` [S3:1–19] carries 1 `sorry` and names the same all-dimensional target the release set for itself.
