# 112 — Beyond the square-root exponent for depth-three circuits

## statement

The preprint's main theorem:

> **theorem**
There is a language $`L\subseteq\{0,1\}^*`$, a deterministic Turing machine
deciding $`L`$, and fixed positive integers $`C,a`$ such that the machine
runs in time at most $`C(n+1)^a`$ on every input of length $`n`$.
If $`f_n`$ is the membership function of $`L`$ on $`\{0,1\}^n`$, then
$$\lim_{n\to\infty}\frac{\log_2 S_3(f_n)}{\sqrt n}=\infty.$$
Equivalently, for every real $`A>0`$, there is an integer $`N_A`$
such that
$$S_3(f_n)>2^{A\sqrt n}\qquad\text{for every }n\ge N_A.$$
No uniformity or bottom fan-in restriction is imposed on the circuits. [S1:21–35]

The Lean proves the same content in a single declaration:

```lean
theorem exists_polynomial_time_language_depth_three_lower_bound :
    ∃ (L : List Bool → Bool) (M : FiniteMultiTapeMachine) (C a : ℕ),
      0 < C ∧ 0 < a ∧
      (∀ w : List Bool, MultiTapeHaltsIn M w (L w) (C * (w.length + 1) ^ a)) ∧
      ∀ A : ℝ, 0 < A → ∃ N : ℕ, ∀ n : ℕ, N ≤ n →
        ∀ D : Circuit3 (Fin n), D.Computes (fun x => L (List.ofFn x)) →
          (2 : ℝ) ^ (A * Real.sqrt (n : ℝ)) < (D.gateCount : ℝ) := by
```
[S2:8–14]

The scope note summarizes 

> The formalized result gives one polynomial-time Boolean language whose exact depth-three OR–AND–OR circuit size eventually exceeds $`2^{A\sqrt n}`$ for every fixed $`A>0`$. [S3:9]

## the match

The formalization is a **clean match** for the preprint's Theorem 1.
Both assert:

1. **One fixed language** $`L`$ and one polynomial-time machine $`M`$ deciding
   it, with the language fixed **before** $`A`$ is chosen. The Lean's
   `∃ (L : List Bool → Bool) (M : FiniteMultiTapeMachine)` binds these first,
   and the `∀ A` is outside that existential [S2:9–12].

2. **Polynomial time** $`C(n+1)^a`$ with $`C, a > 0`$. The Lean encodes this as
   `0 < C ∧ 0 < a ∧ (∀ w, MultiTapeHaltsIn M w (L w) (C * (w.length + 1) ^ a))`
   [S2:10–11].

3. **The lower bound** $`S_3(f_n) > 2^{A\sqrt n}`$ for all sufficiently large
   $`n`$. The Lean writes `2 ^ (A * Real.sqrt (n : ℝ)) < (D.gateCount : ℝ)`
   [S2:14], which is the same inequality with the direction flipped. The
   preprint's equivalent form (line 32) and the Lean's conclusion are
   byte-equivalent modulo notation.

4. **No uniformity, unrestricted fan-in**. The Lean quantifies over all
   `D : Circuit3 (Fin n)` computing $`L`$, with no uniformity constraint on
   $`D`$ [S2:13]. The scope note confirms: "Gates have unrestricted finite
   fan-in and sharing, with free input negations and constants."

| Preprint claim | Lean encoding | Verdict |
|---|---|---|
| $`\exists L, M`$ (fixed before $`A`$) | `∃ (L, M, C, a)` before `∀ A` [S2:9] | **Match** |
| $`M`$ runs in $`C(n+1)^a`$ time | `MultiTapeHaltsIn M w (L w) (C * (w.length+1)^a)` [S2:11] | **Match** |
| $`\forall A > 0,\; \exists N,\; \forall n \ge N`$ | `∀ A, 0<A → ∃ N, ∀ n, N ≤ n →` [S2:12] | **Match** |
| $`S_3(f_n) > 2^{A\sqrt n}`$ | `2^(A*Real.sqrt n) < D.gateCount` [S2:14] | **Match** |
| No uniformity on circuits | `∀ D : Circuit3 (Fin n), D.Computes L →` [S2:13] | **Match** |

## proof-level faithfulness

Protocol: [`README.md`](../../data/proofs/README.md). Family 112 is a
circuit-complexity lower bound. The applicable targets are the quantifier
structure, the growth rate, and the model assumptions:

| Aspect | Preprint | Lean | Verdict |
|---|---|---|---|
| Quantifier order | $`\exists L, M \; \forall A`$ | `∃ L, M, C, a … ∀ A` [S2:9–12] | **Match** |
| Growth | $`2^{A\sqrt n}`$ (unbounded ratio) | `2^(A * Real.sqrt n)` [S2:14] | **Match** |
| Gate model | total gates, unrestricted fan-in | `D.gateCount` over all `Circuit3` [S2:13–14] | **Match** |
| Input negations | free | free (in `Circuit3` model) | **Match** |

No divergence. The formalization is a faithful encoding of the preprint's
theorem.

## findings

- **Clean match**: the Lean's `exists_polynomial_time_language_depth_three_lower_bound`
  encodes every clause of the preprint's Theorem 1 — the one-language
  quantifier, the polynomial time bound, the unbounded-square-root growth,
  and the unrestricted circuit model.
- The scope note [S3:9] accurately describes the formalization and correctly
  notes what the result does **not** assert (no fixed exponent
  $`n^{1/2+\varepsilon}`$, no unrestricted-depth lower bound).
- No faithfulness issues found.
