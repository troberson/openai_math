## Subpolynomial query complexity for log-concave sampling

**Match.** The single comparator target is proven as a `main_results` entry.

The preprint's main theorem [[2]] states three facts: an upper bound Q(d) ≤ C_ε·d^ε for every ε > 0, a lower bound Q(d) ≥ c·log d eventually, and the conclusion γ* = 0. The scope note [S1:9] records the same three claims with the well-conditioned hypotheses (V(0)=0, ∇V(0)=0, I ≤ ∇²V ≤ 2I) and the total-variation error threshold 1/10.

The Lean declaration `exact_source_main` [S2:68–74] is a three-conjunct theorem [[1]]:

1. **Upper bound**: ∀ ε > 0, ∃ C, ∀ d ≥ 2, queryComplexity(d) ≤ C·d^ε. This matches the preprint's subpolynomial upper bound.
2. **Lower bound**: ∃ c > 0, ∃ d₀ ≥ 2, ∀ d ≥ d₀, c·log(d) ≤ queryComplexity(d). This matches the preprint's logarithmic lower bound.
3. **Exponent zero**: gammaStar = 0. The infimal polynomial exponent is zero.

The proof structure assembles three separately proven results: `source_subpolynomial_upper` (line 33), `LowerBound.source_logarithmic_lower`, and `source_gammaStar_zero` (line 63, which wraps the upper bound into an `ExponentBound 0` and takes the infimum). The single comparator [S1:15] (`LogConcaveQuery.lean`) is the shared target.
