# 129 — Exponential state costs for two-way automata

## statement

Family 129 ships two preprints and three proven declarations. The
complementation bound 

> **theorem**
For every integer $`n\ge4`$, set $`H=\{1,\ldots,n-2\}`$ and
$`\Sigma_n=\mathcal R_H`$. There is an $`n`$-state 2NFA $`A_n`$ recognizing
$`L_H`$ such that every 2NFA recognizing
$`\Sigma_n^*\setminus L(A_n)`$ has at least
$$\frac12\,2^{\lfloor(n-4)/127\rfloor}-1$$
states. In particular, there is no polynomial state bound for
complementation that is independent of the finite alphabet. [S1:38–48]

The liveness bound 

> **theorem**
For every integer $`h\ge2`$, the language $`\mathsf{OWL}_h`$ is recognized by a
nondeterministic automaton with $`h+3`$ states using no left moves. Every
equivalent deterministic two-way automaton with $`s`$ states satisfies
$$4(s+2)^2\ge 2^{\lfloor(h-2)/31\rfloor}.$$
If an initially accepting configuration counts as acceptance, $`s+2`$ in
 may be replaced by $`s+1`$. [S2:99–110]

The three `main_results` declarations:

Complementation 

```lean
/-- The real-valued lower bound for arbitrary finite target state sets. -/
theorem complementation_lower_bound_finite (n : ℕ) (hn : 4 ≤ n) :
    ∃ A : TwoNFA (SetRel (Fin (n - 2)) (Fin (n - 2))) (Fin n),
      ∀ (Q : Type*) [Fintype Q], ∀ B : TwoNFA (SetRel (Fin (n - 2)) (Fin (n - 2))) Q,
        B.language = A.languageᶜ →
          (1 / 2 : ℝ) * 2 ^ ((n - 4) / 127) - 1 ≤ (Fintype.card Q : ℝ) := by
```
[S3:30–35]

The combined family (complementation **and** determinization on the
same automaton) 

```lean
/-- Both lower bounds hold for the same n-state liveness witness. -/
theorem explicit_family_main (n : ℕ) (hn : 4 ≤ n) :
    ∃ A : TwoNFA (SetRel (Fin (n - 2)) (Fin (n - 2))) (Fin n),
      A.language = sourceLanguage (Fin (n - 2)) ∧
      (∀ (Q : Type*) [Fintype Q],
        ∀ B : TwoNFA (SetRel (Fin (n - 2)) (Fin (n - 2))) Q,
        B.language = A.languageᶜ →
          (1 / 2 : ℝ) * 2 ^ ((n - 4) / 127) - 1 ≤ (Fintype.card Q : ℝ)) ∧
      (131 ≤ n → ∀ (Q : Type*) [Fintype Q],
        ∀ D : TwoNFA (SetRel (Fin (n - 2)) (Fin (n - 2))) Q,
        D.Deterministic → D.language = A.language →
          (1 / 2 : ℝ) * 2 ^ ((n - 4) / 127) ≤ (Fintype.card Q : ℝ)) := by
```

## the match

All three comparator results are proven. The `natural` division
`(n-4)/127` **is** $`\lfloor(n-4)/127\rfloor`$, so the Lean exponents
match the preprint floors exactly.

| Preprint claim | Lean encoding | Verdict |
|---|---|---|
| Complementation: $`n`$-state 2NFA, complement needs $`\frac12 2^{\lfloor(n-4)/127\rfloor}-1`$ states [S1:40–45] | `∃ A : TwoNFA … (Fin n), … (1/2) * 2^((n-4)/127) - 1 ≤ Fintype.card Q` [S3:31–35] | **Match** |
| Same family, $`n \ge 131`$: deterministic needs $`\frac12 2^{\lfloor(n-4)/127\rfloor}`$ states [S6:10] | `(131 ≤ n → … (1/2) * 2^((n-4)/127) ≤ Fintype.card Q)` [S4:43–46] | **Match** |
| Liveness: $`(h+3)`$-state NFA, no left moves [S2:101–102] | `∃ N : NMachine (Alphabet h) (h + 3), N.NoLeft` [S5:11] | **Match** |
| Liveness: $`2^{\lfloor(h-2)/31\rfloor} \le 4(s+2)^2`$ [S2:106] | `2^((h-2)/31) ≤ 4 * (s + 2)^2` [S5:15] | **Match** |
| Liveness: accepting convention → $`s+1`$ [S2:108–109] | `s + if positive then 2 else 1` [S5:15] | **Match** |

The `explicit_family_main` [S4:35] is a **strengthening**: it proves
the complementation and determinization bounds for the **same**
$`n`$-state automaton $`A`$, not separate families. The preprint states
them for the common family in words; the Lean makes the shared witness
explicit via `A.language = sourceLanguage (Fin (n - 2))` [S4:38].

## findings

- **Full match**: all 3 of 3 comparator results are `main_results`
  entries — complementation, the same-family determinization, and the
  one-way-liveness deterministic lower bound.
- The `explicit_family_main` [S4:35] is a subtle **strengthening**: it
  ties the complementation and determinization bounds to a single
  shared $`n`$-state automaton, which the preprint describes in words.
- The `natural` division matches the preprint's $`\lfloor\cdot\rfloor`$
  floors exactly in all three exponents.
- The scope note [S6:10] accurately describes the combined family and
  correctly flags the one-way-liveness and Sakoda–Sipser results as
  outside scope.
- No faithfulness issues found.
