## One-tape simulation in two-fifths-power space

**Match.** Both comparator targets are proven as `main_results` entries.

The preprint's main theorem [[3]] states two simulation bounds: a time-capped simulator using softO(T^{2/5}) work-space bits, and an unknown-time simulator using softO((t+2)^{2/5}) bits. The scope note [S1:9–11] records both, with the log exponent written as a fixed constant C.

The Lean formalization carries two declarations in `OAI/Computability/SpaceSimulation/Main.lean`, both named in `formalization.yaml` under `OAI.Fifths.Single`:

- `capped` [S2:36–43]: the time-capped bound. The simulator N takes the binary encoding of x and T, returns the source's outcome at time T, and uses space at most c·T^(2/5)·(Log T)^e bits [[1]]. The `exponent` constant is 2/5 by the doc comment.
- `unknown` [S2:61–69]: the no-cap bound. The simulator N reads from x's natural file representation, and on an input that halts at time t uses space at most c·(t+2)^(2/5)·(Log t)^e bits [[2]].

Both bounds are pointwise: the theorems quantify over each input x and time T (or t) individually. The preprint's softO notation `O(f(T)·log^C(T+2))` [S3:61–62] is the same asymptotic class as the Lean's `c · f(T) · (Log T)^e` form with a universal exponent e and constant c.

The single comparator [S1:17] (`OneTapeSpace.lean`) is the shared target for both results.
