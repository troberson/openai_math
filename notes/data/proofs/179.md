## The circulant Hadamard and Barker-sequence conjectures

**Partial.** 1 of 2 comparator targets is proven as a `main_results` entry.

The preprint's main theorem [[2]] states that a real circulant Hadamard matrix of order n exists if and only if n ∈ {1, 4}. The scope note [S1:9] records the same: a real circulant Hadamard matrix of positive order n exists exactly when n = 1 or n = 4, with explicit witnesses for both orders.

The Lean declaration `exists_iff_order_one_or_four` [S2:19–22] [[1]] proves the biconditional ExistsRealCirculantHadamard n ↔ n = 1 ∨ n = 4 for all positive n. The proof (lines 23–33) proceeds by: assuming a Hadamard matrix exists, if n=1 done; otherwise applying `order_reduction` to get n = 4u with u odd, then if u=1 the order is 4; otherwise `not_exists_four_mul_odd_square` contradicts existence.

The scope note [S1:11] also records the even-length Barker-sequence consequence (positive even-length sign sequences with |autocorrelation| ≤ 1 must have length 2 or 4). The `EvenBarker` comparator [S1:18] has **no `main_results` entry** and is a 29-line `sorry` stub. The odd-length Barker classification is outside the scope [S1:11].
