## Subpolynomial dimension reduction in L_p

**Match.** The single comparator target is proven as a `main_results` entry.

The preprint's main theorem [[2]] states the three-part result: for 1 < p < ∞, p ≠ 2, the least distortion-D dimension d_p(n,D) satisfies log n / log(1+2D) ≤ d_p(n,D) ≤ exp(C_{p,D} (log n)^{γ(p)}); at exact embedding (D=1), ⌊(n−1)/4⌋² ≤ d_p(n,1) ≤ C(n,2); and log d_p(n,D)/log n → 0 for D > 1, → 2 for D = 1.

The Lean declaration `source_main` [S2:13–24] [[1]] is a three-conjunct theorem matching the preprint exactly:
1. **Subpolynomial bounds**: ∀ D > 1, ∃ C, ∀ n ≥ 2: log n / log(1+2D) ≤ dimension ≤ exp(C · (log n)^{γ p}).
2. **Exact embedding**: ∀ n ≥ 9: ⌊(n−1)/4⌋² ≤ dimension ≤ n.choose 2.
3. **Logarithmic limits**: ∀ D ≥ 1, log(dimension)/log n → 0 if D > 1, → 2 if D = 1.

The proof assembles `below_main_upper` / `above_main_upper` (split on p < 2 vs p > 2), `exact_dimension_bounds`, and the `Tendsto` limit lemmas. The single comparator [S1:15] (`SubpolynomialLp.lean`) is the shared target.
