## Planar distinct distances and unit-distance bounds

**Not formalized.** Both comparator targets are `sorry` stubs with no Lean implementation.

The preprint's main theorem [[3]] states that for every fixed s > 0, F_n(s) → 0 as n → ∞: in an n-point planar set, the fraction of pins whose most-repeated distance to other points occurs at least n^s times tends to zero.

Neither comparator has a `main_results` entry. The two stubs carry the target statements:

- `PinnedDistances.lean` [S2:29–30]: `main (s : ℝ) : Tendsto (fun n => F n s) atTop (𝓝 0) := by sorry` [S2:29–30] [[1]].
- `PlanarUnitDistances.lean` [S3:19–21]: `main : ∃ C β, 0 < C ∧ 1 ≤ β ∧ β < 4/3 ∧ ∀ n, UNR n ≤ C·n^β := by sorry` [[2]].

No Lean files exist under `lean/OAI/` for either comparator.

**Scope note overclaim:** the scope note [S1:12] states "The formalization proves that there are absolute constants C > 0 and 1 ≤ β < 4/3 such that every finite planar point set of size n determines at most Cn^β unordered unit-distance pairs" — but the unit-distance comparator is a `sorry` stub.
