## statement

The preprint's main theorem is a **deterministic** algorithm:

> {{1}}

No randomness, no probability — "a uniform deterministic algorithm returns
exactly the set $U$". The quasipolynomial bit bound $2^{C(\log_2(L+2))^2}$
appears verbatim in the Lean's carrier.

## the randomized claim is not proved

The scope note [S4:12] describes the formalization as giving "one
**randomized** algorithm … It succeeds with probability at least $7/8$".
The Lean does carry that randomized statement, as the carrier `MainClaim`:

> {{2}}

The $7/8$ factor is the line
`7 * 2 ^ T ≤ 8 * (Finset.univ.filter … CorrectOutput …).card` — the machine
outputs correctly on at least $7/8$ of its random tapes.

**But `MainClaim` is never proved.** It is a `noncomputable def … : Prop`
[Model.lean:113] with no theorem stating it. The only proof in the module is
`deterministic_main` [S3:94], which proves the *deterministic* carrier:

> {{3}}

Note the contrast: `DeterministicMainClaim` requires `Deterministic M` (the
transition ignores the random bit [S2:122–123]) and a single correct run
`CorrectOutput G (run M … (fun _ => false) T)`. There is no probability bound
— the machine is deterministic, so it is either correct or it is not.

The `main_results` entry in `formalization.yaml` names
`deterministic_quasipolynomial_mean_payoff` [S3:100], which is an alias for
`deterministic_main`:

> {{5}}

divergence. The Lean is faithful to the preprint (deterministic algorithm,
matching bound). The scope note names the stronger randomized result, which
the formalization does not establish.
