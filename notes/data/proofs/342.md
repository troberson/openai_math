## Taming implies compatibility on four-manifolds

**Match.** The manuscript's headline [S2:23]{2} is Donaldson's tamed-to-compatible conjecture: if a smooth almost complex structure J on a closed connected smooth real four-manifold X is tamed by a symplectic form, then there is a smooth symplectic form compatible with J. The Lean carrier `Main` [S3:30]{3} proves this: given a tamed almost-complex structure, there exists a compatible symplectic form. The scope note [S1:9]{1} records the same alignment.
