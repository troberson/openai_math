## Asymptotically minimal maxima of real Littlewood polynomials

**Match.** The manuscript's headline [S2:20]{2} is the asymptotic bound: the minimum possible maximum modulus on the unit circle of a polynomial with N consecutive real coefficients in the set ±1 is (1+o(1))·sqrt(N). The Lean carrier `MainStatement` [S3:15]{3} states this in epsilon-language: for every eta > 0 there exists N₀ such that for all N ≥ N₀, there is a real signing with sup-norm ≤ (1+η)·sqrt(N). The (1+o(1)) bound is made precise as the ε-form. The scope note [S1:9]{1} records the same alignment.

The theorem `main : MainStatement` in `Main.lean` [S4:187] is a non-trivial `by` chain using the small-delta budget and almost-sign sampler lemmas. Zero `sorry` in the closure.
